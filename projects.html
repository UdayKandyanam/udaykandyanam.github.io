GO · KUBERNETES TOOLING

KubePulse

A CLI that reads a snapshot of a Kubernetes cluster and reports what is failing, the evidence behind each finding, and the next step. Eight detectors, a collect command that snapshots a live cluster through kubectl, and a diff mode that shows what a fix resolved. Diagnose only: it changes nothing in a cluster.

PYTHON · AGENTS AND EVALUATION

Incident Investigator

A read-only investigator for Kubernetes incidents. It reads a cluster snapshot, scores the likely root cause, and cites the runbook sections behind its diagnosis. Proposed actions are listed as proposals that need human approval, and thin evidence gets a low confidence report instead of a guess. An evaluation set of eight synthetic incidents scores every change.

PYTHON · MCP SERVER

KubePulse MCP

An MCP server over stdio that exposes KubePulse diagnose and diff as tools an LLM client can call, so an assistant can check a cluster snapshot inside a conversation.

PYTHON · RETRIEVAL

Runbook Assistant

Question answering over a folder of runbooks. BM25 ranking implemented from scratch, answers grounded in the text with the file and section cited, and an honest refusal when the runbooks do not cover the question. Ships with seven runbooks, a CLI, and an HTTP API.

A self-service platform API: namespace and deployment lifecycle operations through an authenticated API instead of raw cluster access. Every write is scoped to the team's own namespaces, audit logged, and can be dry run first.
